# React Calendar App

A modern, interactive calendar application built with React and CSS. The app allows to navigate between months, select dates, and manage events through a custom-designed calendar interface.

## ✨ Features

- **Interactive Calendar** — Displays the days of the selected month with weekdays arranged from Monday to Sunday.
- **Month Navigation** — Navigate between months and automatically handle year transitions.
- **Event Creation** — Add events to today or future dates with a specified time and description.
- **Edit Events** — Update existing event times and descriptions.
- **Delete Events** — Remove events when they are no longer needed.
- **Event Sorting** — Automatically sorts events chronologically by date.
- **Time Input** — Specify event hours and minutes.
- **Responsive Layout** — Adapts the interface for different screen sizes using CSS media queries.

## 🛠️ Technologies Used

- **React** — Component-based UI development.
- **JavaScript (ES6+)** — Calendar logic, date calculations, and event management.
- **Vite** — Development server and production build tooling.
- **CSS3** — Custom styling, responsive layouts, transitions, and visual effects.
- **React Hooks** — `useState` for managing calendar navigation, selected dates, event data, and popup visibility.
- **React Icons** — Icons for navigation, event editing, and deletion.
- **Git & GitHub** — Version control and source code hosting.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Martynas-Mockapetris/Calendar.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Calendar
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided in your terminal, typically `http://localhost:5173`.
